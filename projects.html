mosaic: On-Device Multimodal AI

    Personal Project, 2026 (github.com/randomMatrix77/mosaic)
    + Android proof of concept running Qwen 3.5 4B text and image inference locally through llama.cpp, with OpenCL GPU offloading verified on a Galaxy Z Fold 6
    + Jetpack Compose interface connected to Python 3.11 through Chaquopy and JNI
    + EmbeddingGemma text/image embeddings for semantic image retrieval, SQLite persistence and evidence-backed contextual memory
    + Bounded, allow-listed tool loop for memory, image and web retrieval, while final Qwen reasoning stays on-device
    + Verified on the Galaxy Z Fold 6: all 33 Qwen layers offloaded through OpenCL, with streaming answers and a CPU fallback
    + Knowledge graph of entities and claims on top of the SQLite ledger, with correction history and provenance back to the source message
    + Tool requests are strictly validated; the model never gets arbitrary Python, shell or filesystem access
    + Optional web search and page fetching is used for retrieval only; reasoning and answer generation stay on the phone
    + Fold-aware UI: a compact cover-screen workspace, and a navigation rail with a contextual panel when unfolded
    + Kotlin, Jetpack Compose, Python, llama.cpp, OpenCL, SQLite
ui_copycat: Autonomous UI Replication Agent

    Personal Project, 2026 (github.com/randomMatrix77/ui_copycat)
    + Captures live UI structure, styles and interaction states, then generates React/Tailwind replicas from selectively queried DOM/CSS evidence
    + Combines deterministic DOM diffs with multimodal visual evaluation to produce targeted refinement feedback
    + Runs under bounded tool-call and iteration budgets
    + Proof of concept: replicates Stripe's "Products" mega-menu, including its hover interaction
    + Observe: Playwright eagerly captures DOM snippets, computed styles and pre-hover / hover / post-hover screenshots; the agent queries them lazily instead of reading the whole DOM into its prompt
    + Generate: a sandboxed Python REPL with grep and read-slice helpers and a hard output limit, instead of raw browser or terminal access
    + Evaluate: a targeted BeautifulSoup + difflib DOM diff plus a multimodal vision judge that returns PASS/FAIL with refinement pointers
    + Python, LangChain, Gemini, Playwright, React
Zero-Shot Computer-Use Agent

    Personal Project, 2026 (github.com/randomMatrix77/infinite-craft-computer-use · demo video)
    + DOM-independent agent using a locally hosted Gemma 4 26B VLM for visual grounding, inventory reading, planning and coordinate localisation
    + Custom stateful planning loop with action history, step budgets and hallucination checks
    + Deterministic execution with PyAutoGUI
    + Zero DOM/HTML access, no backend API hooks and no hard-coded game logic: everything comes from screenshots
    + Eyes (vision system): screenshots, region cropping and VLM-based inventory reading and target localisation, mapping normalised boxes to screen pixels
    + Brain (planner): local Gemma 4 26B with memory of discovered items and backward chain-of-thought reasoning towards the requested target element
    + Hands (execution): drag, drop and canvas clearing with micro-adjustments and fallbacks
    + Python, Gemma 4, LangChain, PyAutoGUI
